إعداد رابط المقدّم

هذه الخطوة لصاحب المسابقة ومرة واحدة فقط. المقدّم يأخذ الرابط الناتج ولا يرى هذه الصفحة.

  1. افتح صفحة إنشاء الرمز في GitHub
  2. في Repository access اختر Only select repositories ثم khazain-quiz فقط.
  3. تأكد أن صلاحية Contents هي Read and write.
  4. اضغط Generate token وانسخ الرمز، ثم الصقه هنا.

تم، والحفظ يعمل. أرسل هذا الرابط للمقدّم فقط. كل من يملكه يقدر يعدّل المسابقة.
